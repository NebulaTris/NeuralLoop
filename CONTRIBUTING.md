# Contributing

Thanks for wanting to help! Bug reports, ideas, and fixes are all welcome.

## Before you start

- Read `CLAUDE.md` (the rules and contracts) and `docs/ARCHITECTURE.md` (how everything fits together).
- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- `make setup` once, then `make check` must pass before every pull request (tests first: write the failing test, then
  the change).

## Style

Warm, plain copy (Pip is never angry or disappointed; sad only as Silly mode's joke); pure logic in `NeuralLoopCore` / `neuralloop_books` with tests; screens stay thin;
never hand-edit generated files.
